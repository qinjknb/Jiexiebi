# 上位机控制舵机 · 实测记录与成功步骤(2026-10-13)

本文件记录今天从"烧录新固件"到"上位机控制舵机"的完整过程与证据,
以后要复现或排查照着做即可。

## 一、做了什么

1. 改造下位机 `GCWJ\User\main.c`:新增 USART2(PA2=TX,PA3=RX)接收上位机文本命令;
   舵机侧 USART1(PA9 半双工,德晟 v4.01)完全沿用原 `Servo.c`。
2. 编译烧录新固件到 STM32F103C8(详见第三节)。
3. 上位机 `ServoHost\servo_host_gui.py` 连接 CH340(COM9)实测:
   PING 舵机有应答、MOVE 指令已送达(证据见第四节)。

## 二、接线(照此接,已验证)

```
电脑USB ──> CH340(COM9):  TX ──> STM32 PA3(USART2_RX)
                          RX ──> STM32 PA2(USART2_TX)
                          GND ──> STM32 GND(必须共地)
STM32 PA9 ──> 舵机数据线(单线半双工)
舵机电源 ──> 外部电源(5V 或 6~8.4V,勿用板子 3.3V 供电)
ST-Link ──> SWD(烧录用,烧完可留着)
```

### 方法 B:命令行 armcc + OpenOCD(本次实测用的方法)

产物都在 `D:\servo_control\ServoHost\build_tmp\`(main.o、GCWJ.1、GCWJ.hex、GCWJ.map)。

## 五、日常使用速查

1. 打开 `ServoHost\servo_host_gui.py`(PyCharm),依赖 `pip install pyserial`
2. 选 COM9、115200,点连接 → 应收到 `READY` 问候
3. PING 检测舵机 → `OK PING 1`
4. 拖动滑条/填角度 → 移动到目标角度 → `OK MOVE 1 <pos>`
5. 读取当前位置 → `POS 1 <pos>`;恢复演示 → DEMO

位置与角度换算:位置 = 角度 × 4095 ÷ 300(满行程 300° 时)。
